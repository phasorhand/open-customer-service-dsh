# OpenCS 定价与交付模式

> 原则：**不按坐席、不按消息量**。客户买断部署，成本不随业务增长被动上涨。
> 下表为报价框架，具体金额按客户规模与定制量商务议定（内部基准价另行维护）。

## 版本矩阵

| | 试点版（POC） | 标准版 | 企业版 |
|---|---|---|---|
| 目标客户 | 先验证再决策 | 单团队上线 | 多渠道 / 有定制需求 |
| 交付内容 | 部署 + 演示数据 + 两周试运行 | 标准版全功能 + 知识库迁移协助 | 标准版 + 渠道/工具定制开发 |
| 渠道 | webchat | webchat + 企微客服 | 全部 + 定制渠道适配器 |
| 工具对接（订单/CRM） | — | 1 个系统 | 按需 |
| 培训 | 演示讲解 | 运营培训 0.5 天 | 运营 + 运维培训 1 天 |
| 交付周期 | 0.5 天部署 + 14 天试运行 | 1–2 周 | 2–6 周（视定制量） |
| 费用结构 | 低价 / 可抵扣正式版 | 一次性交付费 | 一次性交付费 + 定制人天 |

## 年度维保订阅（标准版起）

- 版本升级（含框架依赖升级的契约测试 + 全量回归验证）
- 远程运维支持（工作日响应；不含登录客户生产环境，除非客户授权）
- 知识库 / 话术优化咨询（每季度一次评测报告解读）

建议定价：一次性交付费的 20–30% / 年。

## 客户自担成本（透明列出，避免后期误解）

| 项 | 说明 | 量级参考 |
|---|---|---|
| 服务器 | 2C4G 单机起步 | 云主机自购 |
| 模型 API | 客户自己的 DeepSeek / 兼容端点账号 | 客服问答单轮约 1–3k token；模板外呼**零模型成本** |
| HTTPS / 域名 | 客户侧反代终结 | — |

## 商务边界（销售红线，对外承诺前先核对）

- **不承诺** SLA 高可用（单实例架构，如实告知；多实例在路线图）
- **不承诺**「全自动无人客服」——产品立场是默认人工审批，放开是客户决策
- **不承诺**除 webchat / 企微以外的渠道「已支持」——其余渠道是定制项
- 模型效果类承诺（准确率、解决率）一律以 POC 实测数据为准，不拍脑袋报数
