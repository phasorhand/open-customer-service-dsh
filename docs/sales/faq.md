# OpenCS 常见问题（采购 / 技术评估）

## 商务

**Q：怎么收费？**
不按坐席、不按消息量。一次性交付费 + 年度维保订阅，价格框架见
[pricing.md](pricing.md)。模型调用成本走客户自己的 API 账号，对客户透明。

**Q：和 SaaS 客服（网易七鱼、智齿、Udesk 等）比，为什么选自托管？**
三个不可替代点：① 数据不出你的机器（合规 / 商密场景硬需求）；
② 成本不随坐席数和消息量线性增长；③ AI 行为可完全管控——自由回复默认人工审批，
审批通过的原文由系统投递，这是多数 SaaS 产品做不到的确定性。
代价是你需要一台服务器和基本运维能力（Docker 起服务、定时备份）。

**Q：POC 怎么做？**
半天部署 + 两周试运行。期间 AI 回复全走人工审批，你们用真实知识库与真实客户
问题验证通过率；两周后拿着评测数据决定是否放开自动回复。流程见
[delivery-checklist.md](delivery-checklist.md)。

**Q：后续升级怎么办？**
维保期内提供版本升级。框架依赖锁定具体 commit，升级先跑契约测试定位破坏面，
再跑全量回归（472 项测试），不做「盲升」。

## 数据与安全

**Q：我们的数据会到你们服务器吗？**
不会。自托管软件，无回传通道、无遥测。唯一出境路径是模型推理调用，
且可通过自建 vLLM / Ollama 做到全量不出机房。详见
[security-whitepaper.md](security-whitepaper.md)。

**Q：AI 乱承诺（「马上给你退款」「肯定包赔」）怎么防？**
四层：① 知识库驱动，答案标注来源；② 自由回复默认人工审批；
③ 每轮回复自动评测「越权承诺」模式并沉淀低分证据；④ 改行为准则的演进提案
强制人工门禁。

**Q：审批会不会拖慢响应？**
待审回复秒级进入控制台队列，运营点一下即投递。确认知识库质量后可把自由回复
加入自动放行档（一行配置），此时仅高风险动作（改生命周期、标记成单）仍需人工。

## 技术

**Q：需要什么规格的服务器？**
单机 2C4G 起步即可（Node.js 单进程 + SQLite，无 Redis / 消息队列 / 托管数据库）。

**Q：支持哪些模型？**
DeepSeek 官方 API 开箱即用；任何 OpenAI 兼容端点（含自建 vLLM、Ollama、
各类网关中转）配 `OPENAI_BASE_URL` 即可。模型可随时切换，不绑定。

**Q：支持哪些渠道？**
网页聊天（HTTP API + WebSocket 实时流，可嵌入你的站点 / App / 小程序）与
**企业微信客服**。其他渠道（抖音、小红书私信等）按渠道适配器模式扩展，可定制。

**Q：知识库怎么维护？会不会要专门培训？**
知识库就是一个目录下的 Markdown 文件。运营用任何编辑器改完保存，检索索引
热更新即时生效，不需要重启、不需要「训练」。

**Q：能对接我们已有的 CRM / 订单系统吗？**
可以。工具层是标准扩展点（`defineTool`），把你们的订单查询 / 工单创建包成工具
即可让 Agent 调用，且自动纳入风险分级与审计。属定制交付范围。

**Q：并发 / 规模上限？**
单实例设计目标是中小团队（参考：50 坐席以下、日均万级消息）。名单外呼场景下
模板首触为毫秒级批量发送，5000 人名单不构成压力。需要多实例水平扩展时有
明确的架构切换点（发件箱换分布式队列），属路线图项。

**Q：服务挂了会怎样？**
联系人、节奏进度、审批队列、审计全部持久化，重启即恢复；唯一丢失的是
进行中对话的模型上下文（客户重新发消息即重建）。健康探针
（`/health/live` `/health/ready`）可接入你们的监控。
