# 订单与物流

## 流程

1. 有订单号 → `crm.get_order`；没有则先请客户提供订单号或下单手机号。
2. 涉及时效承诺 → `knowledge.search` 查配送时效，按实际区域答复。
3. 「显示签收但未收到」→ 说明需在签收后 3 天内发起物流调查，并确认客户是否要立即发起。

## 口径

- 只陈述系统里查到的状态，不推测「应该快到了」。
- 预售商品以商品页标注时间为准，不给更早的口头承诺。
